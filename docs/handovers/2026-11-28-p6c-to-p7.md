   mismatch (it fails closed). Later: leave ignored paths out (`git check-ignore`).

## How plans are written and verified here

As in the P6b→P6c handover: build in a scratch clone (`core.autocrlf=false`), one commit per
task with the gate at each commit (plus `cargo clippy --all-targets --target
x86_64-unknown-linux-gnu -- -D warnings`), run each task's targeted commands at its commit for
the expected summary lines, generate the plan from the history (full contents from `git show`
for created files and files up to 300 lines, exact diffs from `git diff` above that, blob ids from
`git rev-parse`), run `planrun check` and `planrun run --dry-run` on a fresh clone of the base,
and, when time allows, replay it with planrun itself on a fresh clone with `core.autocrlf=true`.
The scripts live in the session scratchpad and are gone with it.

A gotcha from P7, besides the earlier handovers': **never copy a file from the Windows checkout
into the scratch clone as is.** The checkout has `core.autocrlf=true`, so the copy has CRLF, and
the plan's diff becomes a whole-file rewrite with the wrong blob ids. Draft from
`git show <commit>:<path>`, and scan every task commit for `\r` before generating the plan. The
dry run on a fresh clone catches it as `post-mismatch`.
